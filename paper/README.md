# Paper

**Appearance-Invariant Detection of Suggestive Motion via Laban Movement Descriptors**
Jaehoon Ahn, Jeonghan Kong, Moon-Ryul Jung (Sogang University).
SIGGRAPH Posters '26 · [doi:10.1145/3799825.3818709](https://doi.org/10.1145/3799825.3818709)

> Content moderation in online multiplayer 3D virtual environments is increasingly
> automated, yet detection has focused on images, video, and audio, leaving suggestive
> motion a blind spot. We present a motion-only classification pipeline that detects
> suggestive and explicit movement from SMPL skeleton trajectories using Laban Movement
> Analysis (LMA) descriptors. A logistic regression over 61-feature LMA descriptors reaches
> 68% binary SFW/NSFW accuracy (70% random forest) under a leak-free, clip-length-controlled
> protocol — comparable to a learned video model trained on the same motion re-rendered as
> appearance-free video. The indirectness (tortuosity) of each joint's trajectory peaks at the
> suggestive tier, an interpretable marker of the shift from functional to suggestive motion.
